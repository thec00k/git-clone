# git-clone

Home of **Keepsake**, a digital scrapbook in a 3D room.

The app lives in [`keepsake/`](keepsake/). Start there:

- What is built and what is left: [`keepsake/README.md`](keepsake/README.md)
- Run: `cd keepsake && npm install && npm run dev` → [http://127.0.0.1:5174/](http://127.0.0.1:5174/)

## Handoff

The current work branch is [`codex/foundations-and-seasons`](https://github.com/thec00k/git-clone/tree/codex/foundations-and-seasons), which builds on `codex/woodland-composition-proof` and carries the four rooms (Woodland, Beachfront, Neon City, Sky Castle), the seasonal Woodland cabin with Snowy Mountain folded in, the latest scrapbook work, and optional sign-in and backup. Start with [`keepsake/docs/start-here.md`](keepsake/docs/start-here.md) (updated October 25, 2026). `main` remains unchanged. See the [handoff status and branch map](keepsake/docs/handoff-current.md) before continuing.

The approved visual contract is included in [`Keepsake_New_Art_Direction_and_Room_Production_Bible.pdf`](keepsake/docs/Keepsake_New_Art_Direction_and_Room_Production_Bible.pdf); implementation notes and current tasks are indexed in the [Keepsake README](keepsake/README.md).
