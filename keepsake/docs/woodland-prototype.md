# Woodland Writing Room — prototype slice

Implemented on `codex/keepsake-rebuild` in the React/Vite application under `keepsake/`.

## What this slice contains

The default 3D room now loads `public/room/woodland/woodland.glb`. The original room remains at `?theme=classic`; the CSS fallbacks remain at `?room=chamber` and `?room=flat`.

The room has moss-green paneling, oak floorboards and beams, pleated linen curtains, botanical studies, a windowsill fern, and a remodeled beanbag with a depressed seat, filled back, stitched panels, and oatmeal weave. The original desk, book, archive and interaction roots retain their positions. The forest beyond the window is generated by the application with instanced geometry, seasonal colors, day/dusk/night palettes, rain and snow.

The reference direction is interpreted through original work: Edith Finch's lived-in storytelling; LittleBigPlanet's tactile craft; Life is Strange's quiet domestic atmosphere; Sly Cooper's readable silhouettes; and inFAMOUS Second Son's warm/cool light contrast. These are visual influences, not sourced game assets.

## Architecture

- `RoomScene3D.tsx`: room actions, desktop controls, render quality and Canvas boundary.
- `RoomModel.tsx`: assembles the loaded room with interactive props.
- `useRoomAsset.ts`: cached GLB loading, cloned material ownership and environment updates.
- `RoomCamera.tsx`: theme-driven views, movement bounds, seated view and modal input blocking.
- `RoomInteractions.tsx`: hotspot discovery, hit areas and facing-aware prompts.
- `RoomProps.tsx`: drawers, chair, lamp, book contact, clock and legacy prop fallbacks.
- `RoomLighting.tsx`: environment lighting and fan motion.
- `WoodlandScenery.tsx`: instanced forest, seasonal palette and weather outside the window.
- `themes.ts`: typed room manifest, view positions, movement bounds and asset budgets.

The room code is loaded separately from the main application. The existing scrapbook and local IndexedDB store remain the foundation. The memory pass adds optional latest-print and room-quality fields, undoable spread reordering, and a versioned room backup. Social/backend systems remain deferred.

## Desktop targets and measured asset size

Balanced caps pixel ratio at 1.25 and disables shadows. High caps it at 1.75, enables one directional shadow map and adds weather particles. Reduced motion freezes precipitation and the ceiling fan, and snaps the drawer animations. Existing keyboard/listen navigation remains available.

The GLB including the remodeled beanbag measures 5,105,188 bytes, 69,788 triangles, 70 materials and 256 mesh primitives. The validation gates are 8 MiB, 180,000 triangles, 80 materials and 350 primitives. These are asset gates, not measured browser frame rates; runtime props and scenery add geometry and draws. Target: a steady 60 fps on a typical desktop at 1080p, pending browser/device measurement.

Export visible room geometry and `ks_*` empties only, excluding cameras, lights, `Outside_View`, `Win_Glass` and `Beanbag_Original_Backup`. Use GLB, +Y up, apply modifiers, embedded JPEG textures, no tangents. Runtime window scenery must not be covered by the original opaque card. Keep `Desk_Drawer`, `ks_archive_drawer` and fan blades separate. Static new details are merged by material; stitched beanbag seams are one mesh. Textures are capped at 512 pixels for this prototype. Re-export to `public/room/woodland/woodland.glb` and run `npm run check:room`.
