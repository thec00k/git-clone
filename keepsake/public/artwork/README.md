# Original Keepsake artwork

woodland-fern-v1.png and coastal-postcard-v1.png were generated for Keepsake with the built-in image generation tool on September 8, 2026. They are original botanical/coastal illustration candidates, not downloaded Poly Haven, Poly Pizza, Sketchfab or Higgsfield assets.

The botanical print is packed into the Woodland Blender source and appears in both existing frames. Both prints are available under Drawer shop → Creative extras → Keepsake prints, which adds them to the file cabinet for existing scrapbook, printer and map workflows. A larger coordinated collection of stickers, discovery cards and papers remains to be made.
