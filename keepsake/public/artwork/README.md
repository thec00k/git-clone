# Original Keepsake artwork

woodland-fern-v1.png and coastal-postcard-v1.png were generated for Keepsake with the built-in image generation tool on September 8, 2026. They are original botanical/coastal illustration candidates, not downloaded Poly Haven, Poly Pizza, Sketchfab or Higgsfield assets.

The botanical print is packed into the Woodland Blender source and appears in both existing frames. Both prints are available under Drawer shop → Creative extras → Keepsake prints, which adds them to the file cabinet for existing scrapbook, printer and map workflows. Their exact paths are allowlisted for room backup/restore.

The follow-up collection adds eight original vector sticker illustrations in src/components/StationeryArt.tsx: oak leaf, mushroom, moth, teacup, conch, sailboat, sea glass and ocean postmark. Claim the two included packs from the drawer. Five paper choices (plain, woodland, coastal, ruled and dotted) are available in the scrapbook's Pages menu. Paper motifs also decorate correspondence and survive saving, undo/redo, thumbnails, page curls and print export. These are repository-authored vector illustrations, not Higgsfield outputs or third-party assets.
